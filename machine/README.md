# 机器码实验：图形界面引导

本目录与上一版原型分开，用于重新开始制作。`gui-bootstrap.hex` 直接记录手写的十六进制文件字节；它没有通过汇编器或高级语言编译器生成。文件包含 PE 头、x86-64 指令、Windows 导入表和文本。

Windows 自带的 `certutil` 可以把这些字节转换为可执行文件：

```text
certutil -f -decodehex machine\gui-bootstrap.hex machine\gui-bootstrap.exe 4
```

该可执行文件验证双语界面。首个窗口使用 Windows 的“是／否／取消”按钮。“是”进入中文提示，“否”进入英文提示，取消或按 Esc 直接退出。默认选中“取消”。目前只检查了 PE 结构和分支地址，尚未实际操作窗口。安装文件和配置 PATH 的功能待实现。

| 文件偏移 | 内容 |
| --- | --- |
| `0x0000` | DOS 头；`0x003c` 指向 PE 头。 |
| `0x0080` | x86-64 PE 头，子系统为 Windows GUI。 |
| `0x0200` | 入口指令：调用 `MessageBoxW`、根据结果选择中文或英文消息，再调用 `ExitProcess`。 |
| `0x0400` | Windows 函数导入表和 UTF-16 文本。 |

该引导实验现由仓库根目录的正式安装入口取代。`cc.exe` 属于早期原型。

新版本使用 `.cir` 扩展名。手写的 `circle.hex` 已实现命令行入口，可用以下命令转换并运行：

```text
certutil -f -decodehex machine\circle.hex machine\circle.exe 4
.\machine\circle.exe help
.\machine\circle.exe --help
.\machine\circle.exe version
.\machine\circle.exe build examples\add.cir -o add.exe
.\add.exe
$LASTEXITCODE
```

已实测无参数时显示帮助，未知命令返回退出码 1。`circle run 文件.cir` 按 1 KiB 分块读取。当前接受十进制整数和以 `+` 连接的整数表达式，将结果作为进程退出码。操作数和结果的有效范围为 `0` 至 `4294967295`，符号两侧可有 ASCII 空白。空文件或纯空白返回 0。缺少操作数、超出范围及其他语法以 `行:列: Invalid source` 报告。位置从 1 开始，列按源码字节计数，指向检测到问题的字节或文件末尾。文件打开或读取失败报告 `Cannot open.`。两种错误均返回 1，并向标准错误输出消息。运行 `examples\add.cir` 后，PowerShell 的 `$LASTEXITCODE` 为 42。开发顺序与验收标准见 [ROADMAP.md](../ROADMAP.md)。

`circle run` 和 `circle build` 都支持在表达式末尾加 `!`。出现该标记时，程序以十进制加换行写入标准输出，成功时返回退出码 0。示例 `examples\print.cir` 输出 `42`。省略标记时，表达式结果仍作为进程退出码。

最后一个操作数可写为 `?`。例如，在 PowerShell 中运行 `'5' | .\machine\circle.exe run examples\input.cir`，会输出 `24`。直接运行和编译产物都在执行时从标准输入取一个 ASCII 数字 `0` 至 `9`。输入为空、首字节不是数字、读取失败或结果超出 `0` 至 `4294967295` 时返回 2。此版本只读取首字节。

源码可以在最终表达式前声明多个局部整数。例如 `left: u8 = 19; limit = 23; left + limit!` 输出 `42`。显式类型 `u8` 的初值范围是 `0` 至 `255`，`u16` 的初值范围是 `0` 至 `65535`，`u32` 的初值范围是 `0` 至 `4294967295`。省略类型时按 `u8` 检查。初值须为十进制字面量。加法使用 `u32` 范围。名称长 1 至 8 个字符，以 ASCII 小写字母开头，后续可用小写字母、数字或下划线，每个程序最多声明 26 个变量。未知类型、未声明的引用和重复声明会报错。编译器在编译时解析变量引用。

`#` 开始行注释，到换行或文件末尾结束，可单独成行或放在代码后。示例见 [readable.cir](../examples/readable.cir)。

文件开头可带 UTF-8 BOM，BOM 不计入错误列号。示例见 [utf8-bom.cir](../examples/utf8-bom.cir)。

最终表达式支持一次无符号小于 `<` 或大于 `>` 比较，成立时结果为 1，否则为 0。两侧可以各自包含加法，比较在编译时求值。示例见 [comparison.cir](../examples/comparison.cir)。

最终表达式支持一次按位与 `&`、按位或 `|` 或异或 `^`。两侧可各自包含加法，先求和再按位运算，使用 `u32` 范围。这些操作在编译时求值，暂不支持运行期输入作为其操作数。

最终表达式支持一次无符号减法，例如 `total - 18!`。两侧可用字面量、局部变量和加法，先分别求和，再相减。减法在编译时求值，结果为负数时报告语法位置。减法暂不用于循环体、条件分支或赋值。

可以在最终表达式前用 `set 名称 = 表达式;` 更新已声明的局部变量。字面量、局部变量和加法构成的赋值按出现顺序求值，结果必须符合目标变量声明时的类型。编译器在生成 EXE 前求出这些值。`set` 是保留字。

`set 名称 = ?;` 将变量绑定到运行时读取的一个 ASCII 数字。每份源码最多使用一次这种赋值，目标变量随后必须在最终表达式中引用一次，作为加法的最后一个操作数、条件测试或循环次数。不能在后续赋值中重新设置该变量或读取它。示例见 [assignment-input.cir](../examples/assignment-input.cir)。

最终表达式可以写成 `条件 ? 非零分支 : 零分支`。分支可使用整数字面量、局部变量和加法，两支都会检查语法和溢出。末尾的 `!` 输出选中的结果。常量条件在编译时选支，条件写作 `?` 时在运行期读取一个 ASCII 数字。例如 `? ? 42 : 7!` 输入 `0` 输出 `7`，输入其他数字输出 `42`。每份源码支持一个条件表达式，分支内部暂不支持嵌套条件或输入。

计数循环写作 `次数 {步长}`，也可以用分号分隔多个累加表达式。编译器检查并合并每轮的固定增量，生成的程序在运行期累加。`6 {2; 3; 2}!` 输出 `42`，零次循环输出 `0`。分号用于分隔表达式，不能放在右花括号前。常量次数最多为 65535，结果超出 `u32` 范围会在执行或生成 EXE 前报错。`?` 或用 `set 名称 = ?;` 绑定的变量也可以作为次数，运行时读取一个 ASCII 数字，输入错误或累加溢出返回 2。示例见 [repeat-body.cir](../examples/repeat-body.cir)。

循环体可用 `变量 += 步长` 选定一个已声明的 `u32` 变量作为累加器。循环从变量的初值出发，在运行期逐轮更新，并将最终值作为循环结果。零次循环返回初值。例如 `total: u32 = 12; 6 {total += 5}!` 输出 `42`。当前支持单一累加器和固定增量，循环内的通用赋值和嵌套控制流仍待实现。示例见 [repeat-assignment.cir](../examples/repeat-assignment.cir)。

`circle build 源文件.cir -o 输出.exe` 生成 1.5 KiB 的 Windows x64 程序。编译器将除最后一个操作数外的各项合为一个部分和。生成的程序先检查 `%LOCALAPPDATA%\Circle\circle.exe` 是否存在且为文件，失败时立即以 126 退出，再根据源码完成求和、读取输入、选支或计数循环，并输出结果或以结果退出。安装检查限于文件路径，尚未校验身份、签名或版本。输出文件已存在时返回 `Cannot write output.`。编译器内嵌 [exit-template.hex](exit-template.hex) 的 PE 字节，生成时写入文件偏移 `0x0281` 和 `0x0287` 的操作数、偏移 `0x0298` 的模式标记，以及偏移 `0x029c` 的运行期非零分支结果或循环次数。图形安装器会创建该安装路径。

## 双语图形安装器

[CircleSetup.exe](../CircleSetup.exe) 内含当前版本的编译器，并使用项目 logo 作为 Windows 图标。默认显示中英文选择、安装确认及结果提示。确认后安装到 `%LOCALAPPDATA%\Circle\circle.exe`，使用同目录临时文件写入，再替换目标。取消不写入文件。

`CircleSetup.exe --quiet` 执行相同的文件安装和 PATH 更新。安装器保留用户 PATH 的原有内容和注册表值类型，按大小写不敏感的完整目录项检查重复。对可展开值，还识别 `%LOCALAPPDATA%\Circle`。更新后向 Windows 发送环境变更通知。

`CircleSetup.exe --uninstall` 打开中英文卸载确认界面，`--quiet-uninstall` 静默卸载。卸载移除当前用户安装目录下的 `circle.exe`，并删除 PATH 中第一个与安装目录完全匹配的绝对路径项。其他文件、其他 PATH 项和手动添加的可展开别名会保留。文件或对应 PATH 项已不存在时，卸载仍可成功。退出码 0 表示成功，1 表示文件操作失败或参数错误，2 表示用户取消，3 表示文件操作已完成但 PATH 更新失败。

安装器的手写 PE 字节位于 [circle-setup.hex](circle-setup.hex)。用以下 Windows 命令复现：

```text
certutil -f -decodehex machine\circle-setup.hex CircleSetup.exe 4
```

内嵌编译器起始于安装器二进制的 `0x1700`，本版长度为 `0x2c00` 字节。更新编译器时，需要同步更新安装包内的负载及长度。
